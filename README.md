# 🔷 Pattern & Symmetry Game - Part 2
The second installment in the Pattern & Symmetry series, featuring advanced spatial reasoning challenges, complex multi-axis symmetries, rotational logic, and intricate grid patterns!

## 🚀 Features
- **Advanced Symmetry Modes:** Tackle rotational, bilateral, and multi-axis reflection puzzles.
- **Complex Pattern Sequences:** Solve intricate geometric arrangements, tessellations, and advancing patterns.
- **Escalating Difficulty:** Designed as the next step up from Part 1, offering more challenging grid sizes and tighter rules.
- **Instant Visual Validation:** Immediate visual cues to help identify matching segments and learn symmetry concepts hands-on.
- **Lightweight Architecture:** Quick-loading, pure front-end design optimized for smooth browser performance.

## 🎮 How to Play
1. Start a new game session and review the level objective.
2. Analyze the source pattern, line of symmetry, or sequence rule.
3. Click or tap grid cells to mirror the active design, or select the correct completing piece.
4. Verify your solution to score points, maintain streaks, and unlock higher-tier puzzles!

## 🛠️ Getting Started & Installation
To run or test this project locally:

1. **Clone the repository:**
    git clone [https://github.com/satlakh1421-alt/Pattern-And-Symmetry-Game-Part-2.git](https://github.com/satlakh1421-alt/Pattern-And-Symmetry-Game-Part-2.git)

2. **Navigate to the project directory:**
   cd Pattern-And-Symmetry-Game-Part-2

3. **Run the game:**
   Open index.html directly in your browser, or spin up a local server:
   python3 -m http.server 8000
